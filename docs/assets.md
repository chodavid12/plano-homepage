# 실제 에셋 추가 가이드 (사진 · 로고)

채팅에 붙인 이미지는 코드로 자동 반영되지 않습니다. 아래 위치에 **파일로** 올리면 사이트에 적용됩니다.

## 업로드 방법 (GitHub 웹에서 가장 간단)
1. GitHub 레포 `chodavid12/plano-homepage` → 브랜치 **`claude/pensive-pascal-no9crd`** 선택
2. 해당 폴더로 이동 → **Add file → Upload files** → 파일 드래그 → **Commit**
3. 올리신 뒤 알려주시면 코드에 연결하고 프리뷰를 갱신합니다.

## 파일 위치 / 이름

| 용도 | 경로 | 비고 |
|---|---|---|
| 메인 배경 사진 | `public/hero.jpg` | 가로형 고해상(예: 2000px+). 올리면 스플래시 배경 자동 적용(없으면 시드 SVG) |
| 로고(밝은 배경용) | `public/brand/logo.svg` 또는 `logo.png` | 헤더·푸터용. **투명 배경** 권장 |
| 로고(어두운 배경용) | `public/brand/logo-white.svg` 또는 `logo-white.png` | 스플래시(어두운 배경)용 흰색 버전 |
| 샘플 포트폴리오 사진 | `public/portfolio/<프로젝트>/*.jpg` | 디자인 확인용. 실서비스 사진은 Notion 동기화로 자동 유입 |

## 참고
- **포트폴리오 사진**은 최종적으로 **Notion DB에서 자동 동기화**됩니다(코드에 넣지 않아도 됨). 위 `public/portfolio/`는 연동 전 디자인 확인용입니다.
- 로고가 **투명 배경 SVG**면 가장 선명합니다. 베이지 배경이 포함된 PNG는 헤더/스플래시에서 배경이 비쳐 보일 수 있어, 가능하면 배경 없는 파일로 주세요.
- 메인 배경은 코드 고정(노션 동기화 대상 아님)이라 `public/hero.jpg` 교체로 관리합니다.
